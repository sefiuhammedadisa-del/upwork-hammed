# Hammed Sefiu | Book Formatting website

## Publish on GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io` (or any name).
2. Upload everything in this folder, keeping the `samples` folder as it is.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root → Save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/` in a minute or two.

## After it is live
- In `robots.txt` and `sitemap.xml`, replace `YOUR-USERNAME.github.io` with your real address.
- In `index.html`, uncomment the `<link rel="canonical">` line and put your address in it.
- Submit the sitemap in Google Search Console and Bing Webmaster Tools.
